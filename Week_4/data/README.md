# Week 4 Data

This folder contains the datasets I used for **Week 4: HealthConnect Project Kickoff & Problem Understanding**.

* **`HealthConnect_Appointment_Data.csv`** – The main appointment dataset containing patient demographics, booking details, reminder information, distance to clinic, and appointment outcomes (Attended, No-Show, Cancelled).
* **`HealthConnect_Data_Dictionary.csv`** – The data dictionary explaining each variable, its data type, and quality notes (e.g., limited missing values in `distance_to_clinic_km` and `waiting_time_minutes`).

These files form the foundation of my no-show prediction problem definition and will support my Week 5 modelling work.
